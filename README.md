A humpback whale the size of the room, bursting out of a small framed seascape painting in a sunlit gallery — seawater exploding into spray while the painted sea stays flat inside the frame, a small boy below reaching up toward the whale. One image, one jolt of awe: the art coming alive and breaking into the room, built to make make.fun's AI judge excited.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, refusing anything over the 1 MiB / 1024x1024 gate and verifying the copy byte-for-byte with sha256. The image carries no text, so there is nothing for a judge to misread — the idea reads at a glance: scale shock, surprise, and motion in a single frame.
